### 中高危（1 条）

**B1 · 「跳过 / 引用丢弃」被当成「干净跑」→ 存量 open 被静默转 fixed（假熄灯；两条侧门绕开 G2 守卫）** ★三透镜同报

- **探针实证（三份，各自复现）**：
  - 质量 P1（`quality_probe.out`）：第一轮词表命中 → concrete 问题 `open`；第二轮无候选跳过 → 该问题 `fixed`，`summary={'title':'动作具象化','ran':True,'found':0,'error':None}`。
  - 效率（`s2_probe2.out` §2）：第二轮模型改写法（`ref:"99->01"` 不可解析）→ `ran=True, found=0, error=None`，该行转 `fixed`（counts `open=0, fixed=5`）；同族第二例（carrier 判错）同结果；**对照**：回包非 JSON 走 error 通道（`ran=False` + error）——「大门有守卫、小门没有」。
  - 高度（`s2_alt_probe.py`）：词表置空后再跑 → LLM 调用 **0 次**、原 open（`shot 1`「看着」不具象）→ `fixed`；前端 `auditset.js:119-121` 清空词表（`split(...).filter(Boolean)` 得 `[]`）**无任何守卫**（同文件 `:104-109` 对 int 参数却显式拒绝 <1）＝用户两步可达。

- **severity：低｜ effort：small｜ 来源：复用 `BUG-S2-1`｜ confidence：high（机制实证）/ medium（真实可达性）**
